# Skills

Личный набор скиллов для Claude Code. Скилл описывает агенту, как действовать в конкретной ситуации: ревью кода, диагностика багов, техническая документация и другие повторяющиеся виды работы.

## Структура

Каждый скилл лежит в `.claude/skills/<name>/` и содержит файл `SKILL.md`: YAML-фронтматтер (`name`, `description`, опционально `disable-model-invocation`, `argument-hint`) и тело на Markdown. Часть скиллов добавляет подпапку `agents/` с конфигурациями субагентов, которых скилл запускает. `diagnosing-bugs` добавляет ещё и `scripts/`.

`skills-lock.json` в корне фиксирует источник каждого скилла: репозиторий на GitHub, путь до `SKILL.md` в нём и хеш содержимого. Это список того, что установлено, и откуда.

## Скиллы

Столбец «Запуск» показывает, как скилл включается. При **auto** Claude сам решает по `description`, когда задача подходит. При `/имя` скилл срабатывает только по явному вызову (в его фронтматтере стоит `disable-model-invocation: true`).

| Скилл                | Запуск               | Что делает                                                                                                                                           |
| -------------------- | -------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| `blast-radius`       | `/blast-radius`      | Находит, что изменение может сломать за пределами диффа, и подтверждает это, реально запуская код, а не описывая его.                                |
| `bro`                | `/bro`               | Пересказывает последнее сообщение агента простым языком, без жаргона.                                                                                |
| `grilling`           | auto                 | Дожимает пользователя вопросами по плану или решению, пока не появится общее понимание.                                                              |
| `handoff`            | `/handoff`           | Сжимает текущий разговор в документ передачи для другого агента.                                                                                     |
| `teach`              | `/teach`             | Обучает пользователя новому скиллу или концепции в рамках рабочего пространства.                                                                     |
| `technical-writing`  | `/technical-writing` | Слоистый стандарт технического письма: структура Diátaxis, стиль предложений Google, правила инструкций STE, синтаксис Global English.               |
| `unslop`             | auto, всегда         | Убирает AI-паттерны из любого текста и добавляет человеческий голос.                                                                                 |
| `verify-this`        | auto                 | Проверяет утверждение свежим локальным доказательством: baseline, изменение, сравнение, вердикт VERIFIED, NOT VERIFIED или INCONCLUSIVE.             |
